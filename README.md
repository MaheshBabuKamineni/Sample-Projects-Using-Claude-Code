# Sample Projects Using Claude Code

A collection of small projects generated with [Claude Code](https://claude.com/claude-code), Anthropic's AI coding agent. Each project folder has its own README covering what the project does, how to run it, and the exact prompt given to Claude Code to generate it.

## Projects

| Project | Description | Stack |
| --- | --- | --- |
