# Sample Projects Using Claude Code

A collection of projects built or explored with [Claude Code](https://claude.com/claude-code), Anthropic's AI coding agent. Each project folder has its own README covering what the project does, how to run it, sample output, and the exact prompt given to Claude Code.

## Projects

| Project | Description | Stack |
| --- | --- | --- |
| [Future Me](future-me/) | Write letters to your future self that stay sealed, with a live countdown, until the date you choose. | HTML, CSS, vanilla JavaScript |
| [Color Palette Explorer](color-palette-explorer/) | Browse, search and copy 20 handpicked colors, with dark mode and a Recently Viewed history saved by the server. | Node.js, Express, HTML, CSS, JavaScript |
| [Faker](faker-next/) | Open-source library for generating realistic fake data. **Not generated by Claude Code:** a copy of [faker-js/faker](https://github.com/faker-js/faker) (MIT) that was explored and explained with Claude Code. | TypeScript |
