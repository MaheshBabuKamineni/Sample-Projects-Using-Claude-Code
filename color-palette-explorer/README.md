# Color Palette Explorer 🎨

Browse 20 handpicked colors, search them by name or HEX code, and click any color to copy its HEX code and change the page background to it. Your last five clicked colors appear as small swatches.

The app runs on a small Node.js and Express server that serves the page and saves each color click, with a timestamp, to a local JSON file.

> **Built with Claude Code.** All of the code in this folder was generated by [Claude Code](https://claude.com/claude-code), Anthropic's AI coding agent, from the prompt below. Claude Code set up the project, installed the dependencies, wrote every file and started the server.

## Features

- **20 handpicked colors** in a responsive grid. Each card shows the color's name and its HEX, RGB and HSL values, in a text color chosen to stay readable on that card.
- **Hover effect.** Cards scale up slightly and gain a soft shadow.
- **Click to explore.** Clicking a card copies its HEX code to the clipboard, smoothly changes the page background to that color, and shows a "Copied HEX to clipboard!" message.
- **Live search** that filters colors by name or HEX code as you type.
- **Dark mode toggle** in the top right corner. Your choice is remembered.
- **Animated hero section** with a slowly shifting gradient behind the title.
- **Recently Viewed.** The last 5 colors you clicked appear as small round swatches. Click history is saved on the server, so it survives a page refresh or a server restart.
- **Typography** uses Poppins for headings and Inter for body text, from Google Fonts.

## Running it

You need [Node.js](https://nodejs.org/) 18 or later.

```bash
cd color-palette-explorer
npm install
npm start
```

Then open http://localhost:3000. To use a different port, set the `PORT` environment variable, for example `PORT=4000 npm start`.

The server listens only on your own computer (`127.0.0.1`), so other devices on your network can't open it.

### API

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/colors` | Returns all 20 colors. |
| `GET` | `/api/recent` | Returns the last 5 distinct colors clicked, newest first. |
| `POST` | `/api/clicks` | Body `{ "hex": "#0F766E" }`. Saves the click with a timestamp and returns the updated recent list. Unknown colors are rejected with `400`. |
